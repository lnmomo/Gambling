# gambling
This project aims to build a multi-agent workflow for pre-match decision-making in football betting. The system automatically collects official betting odds, external market odds, team historical performance, news intelligence, weather, and schedule information, then calculates the "model true probability" for each betting option in every match. It compares these probabilities with the SP values from China's Sports Lottery football betting market to identify potential positive expectation opportunities. The ultimate goal is not merely mechanical prediction of outcomes, but to establish a backtestable, interpretable, risk-controllable, and iteratively sustainable probabilistic decision-making platform.
