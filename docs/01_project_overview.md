# 项目概览

## 背景

本项目构建了一个面向竞彩足球赛前决策的多 Agent 概率系统。系统通过采集官方 SP、外部市场赔率和历史比赛数据，结合增强足球模型、概率校准、True Odds Engine、Edge Quality Filter、资金风控和 Live Shadow Validation，对比赛选项进行概率估计与风险过滤。

项目核心不是简单预测胜平负，而是判断模型概率相对官方 SP 是否存在足够可靠的正期望，并通过 CLV、回测和真实影子验证持续评估模型质量。

## 项目目标

1. 将官方 SP、外部赔率和历史比赛数据整合为统一的赛前决策视图。
2. 生成可解释的模型概率、市场概率、公平赔率和 EV。
3. 使用 True Odds Engine 与 Edge Quality Filter 过滤低质量机会。
4. 用 walk-forward backtest、CLV 和 shadow validation 评估策略稳定性。
5. 用 bankroll / portfolio risk control 限制单场、单日、联赛和相关性风险。
6. 提供可运行、可演示、可审计的工程闭环。

## 为什么只看 EV 不够

EV 为正并不代表推荐可靠。赔率可能过期，数据样本可能不足，模型与市场可能严重分歧，球队历史特征可能缺失，或者同一批推荐集中在高相关比赛上。因此系统在 EV 之外加入：

- 概率不确定性与 lowerBoundEV。
- 多方法去水和市场一致性检查。
- Edge Quality 分层。
- 动态阈值。
- Critic 拦截规则。
- 资金与组合风险控制。
- CLV 与赛后评估。

## 为什么需要 True Odds / Edge Quality / Shadow Validation

True Odds Engine 用多种去水方法估计更稳健的公平赔率，并输出不确定性。Edge Quality Filter 判断一个正 EV 是否足够干净、稳定、可解释。Live Shadow Validation 允许新配置在真实赛前数据上旁路运行，只记录结果，不改变生产推荐，避免未经验证的参数直接影响用户视图。

## 能力边界

系统可以辅助概率研究、回测分析、推荐过滤和风险诊断。它不能直接观察真实概率，不能保证未来收益，不能绕过数据源限制，也不会自动下注。新闻、天气、首发等扩展信号只有在真实接口配置并通过质量检查后才适合进入生产判断。

## 风险声明

系统不保证盈利，不自动下注。历史回测不代表未来结果。所有推荐都只是概率性判断，可能出错，用户需要自行承担风险。
