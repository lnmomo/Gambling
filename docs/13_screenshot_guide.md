## 截图建议

1. Dashboard overview：展示官方比赛池和系统概览。
2. Recommendations list：展示推荐过滤与 NO_BET 原因。
3. Match Detail True Odds Analysis：展示单场概率解释。
4. Multi-devig comparison：展示多方法去水结果。
5. Edge Quality Panel：展示 edge 分层、lowerBoundEV 和动态阈值。
6. Backtest metrics：展示 ROI、CLV、Brier、Log Loss。
7. Edge Quality Optimizer：展示配置优化结果。
8. Blocked Recommendation Analysis：展示被拦截样本复盘。
9. Live Monitor snapshots：展示赔率快照刷新状态。
10. Bankroll risk panel：展示 stake 和暴露限制。
11. System Health：展示健康检查。
12. Settings risk config：展示配置与安全开关。
13. Shadow Validation / Promotion Gate：展示 shadow metrics 和人工确认链路。
