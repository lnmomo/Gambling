# 市场残差概率模型：12 个月嵌套 Walk-Forward 报告

## 算法

1. 使用去水开盘赔率概率作为基准，不直接与市场对抗。
2. Elo 与 Poisson 只负责预测相对市场概率的残差。
3. 每个结果方向分别使用岭回归拟合残差，降低特征共线性和过拟合。
4. 使用 PAV isotonic 对概率做单调校准。
5. 按联赛历史样本量进行经验贝叶斯式收缩；样本少的联赛自动回到市场概率。
6. 根据训练误差计算概率下界，并以概率下界计算保守 EV。
7. 使用受限 Fractional Kelly：每日最多 100 元、单场最多 20 元、同联赛最多 40 元。
8. 每个外层测试月之前，以过去 3 个月作为内层验证，选择 EV 阈值、赔率上限和 Kelly 比例。
9. 内层验证没有至少 20 笔且 ROI 为正的参数时，该月自动空仓。

## 防泄漏

- 赛事特征按日期顺序生成。
- 同一天全部预测完成后才读取当天结果更新 Elo。
- 每个测试月只使用该月之前的数据训练和选择参数。
- 仅使用开盘赔率，不使用收盘赔率。

## 外层测试

- 区间：2024-06 至 2025-05，共 12 个月。
- 概率评估：6,592 场。
- 允许投资：4 个月。
- 自动空仓：8 个月。

| 指标 | 结果 |
|---|---:|
| 投资笔数 | 17 |
| 命中 | 7 |
| 总投入 | 17.52 |
| 净收益 | +0.10 |
| ROI | +0.57% |
| 最大回撤 | 7.23 |
| 最大单日投入 | 2.29 |
| Brier Score | 0.198041 |
| Log Loss | 0.995108 |
| ECE | 0.005154 |

## 治理结论

`NEED_MORE_DATA`

概率校准误差较低，但 17 笔投资远低于 100 笔晋升门槛。正收益只有 0.10 元，不足以证明可持续优势。新模型保持 challenger / shadow 状态，不自动替换生产策略。后续需要继续滚动积累不同赛季和联赛样本，并观察 ROI、CLV、校准误差和最大回撤是否同时满足晋升标准。
